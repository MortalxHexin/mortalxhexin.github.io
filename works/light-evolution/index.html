點燈的光暈

每一代都有一張點燈、一張熄燈的照片。點燈時把兩張按亮度混合，再在光源處疊三層「加亮」的徑向漸層：核心、光暈、環境光。

function glow(x, y, k, col) {
  ctx.globalCompositeOperation = 'lighter';     // 光是「加」上去的
  for (const [r, a] of [[90, .5], [260, .2], [620, .09]]) {
    // 三層：核心、光暈、環境光
    const g = ctx.createRadialGradient(x, y, 0, x, y, r);
    g.addColorStop(0, `rgba(${col}, ${a * k})`);
    g.addColorStop(1, 'rgba(0, 0, 0, 0)');
    ctx.fillStyle = g;
    ctx.fillRect(x - r, y - r, 2 * r, 2 * r);
  }
}

搖曳的火焰

照片裡的火焰是靜止的。把它切成 3 像素高的橫條，每一條左右偏移，越靠近火尖擺得越大，靜止的照片就燒了起來。

// 火焰切成 3 px 高的橫條，越靠近火尖擺得越大
const sway = y => {
  const h   = (base - y) / (base - top);   // 0 在底部，1 在火尖
  const amp = 26 * Math.pow(h, 1.6);
  return amp * (.6 * Math.sin(t * 5.1 + y * .012)
              + .4 * Math.sin(t * 8.7 + 1.3 + y * .02));
};
for (let y = top; y < bottom; y += 3)
  fg.drawImage(flame, 0, y, w, 3,         // 取一條
               x + sway(y), y, w, 3);     // 偏移後放回去

縮成地球

最後一盞燈先收成一個柔邊光點，再落到台灣的位置。地球照片從 16 倍放大拉回 1 倍，放得越大越模糊，避免看到像素。

const q = smooth((t - t0) / 4.5);             // 4.5 秒拉遠
const E = Math.pow(16, 1 - q);               // 放大 16 倍 → 1 倍
ctx.filter = `blur(${Math.max(0, (E - 2) * 1.6)}px)`;
ctx.drawImage(earth, A[0] - TW[0] * E, A[1] - TW[1] * E,
              w * E, h * E);
ctx.filter = 'none';
// 最後一代的畫面用柔邊遮罩收成光點
feather(lampFrame, 1 - E / 16);
